# Contract release readiness

## Current state

ACV1-CONTRACTS (issue #5) remains blocked. The maintained [shared-contracts catalog](https://github.com/Jevelopers-neatHack-2026/shared-contracts/blob/c4caaccc2ea63b273eeac17ed89af8ac64f6bbde/docs/contract-catalog.md) is design documentation; the inspected owner trees did not contain executable schemas, generated validators, or the DecisionPort/approval/budget adapters required for fixture conformance. `fixtures/contracts/release.json` records the exact external owner actions without copying those contracts.

The pending descriptor is a harness readiness inventory, not a runtime schema or a new contract authority. A canonical release must come from shared-contracts and carry owner-reviewed consumer handoffs. The v2 verifier checks content hashes, independently trusted owner evidence, every declared runtime schema, the exact JSON Schema property set for each schema/contract/primitive tuple, and a separate fixture mapping for every tuple before it considers execution. It does not generate schemas, infer field aliases, or count coverage tags.

The field extractor accepts only an explicitly declared JSON Schema Draft 2020-12 dialect (`https://json-schema.org/draft/2020-12/schema`) within a bounded subset. It follows local JSON Pointer references and the standard composition, conditional, dependency-schema, `prefixItems`, `items`, `contains`, and `unevaluatedItems` applicators. Positional tuple fields use numeric path components and general array elements use `/*`. External/dynamic references, legacy dialects and applicators, unknown keywords, `patternProperties`, open/dynamic `additionalProperties` or `unevaluatedProperties`, and open item schemas are unsupported and fail closed. Traversal is bounded to 20,000 work steps, 2,048 reference expansions, 10,000 unique fields, 4,096 bytes per path, and 1 MiB total path bytes. A limit returns a typed blocker before adapter execution. These are parser safety limits, not owner acceptance targets.

The local adapter protocol is `agent-creative.contract-fixture-adapter/v2`. It is an internal tool exchange, not a DecisionPort, application port, or approval authority. The adapter receives exact schema/fixture paths and hashes but never receives expected outcomes or expected serialization hashes. Optional adapter dependencies must be declared by relative path and SHA-256; undeclared package files are not mounted. Its independently evidenced bytes must return typed case identities, observed input hashes, outcomes, and actual serialized bytes; the parent hashes those bytes. A response that echoes expected values or omits observed bytes fails.

`offline_attested` and other local status strings do not establish isolation or owner provenance. The runner requires an owner-evidence index outside the repository and an exact SHA-256 supplied independently through protected runner configuration (`ACV1_OWNER_EVIDENCE_INDEX` and `ACV1_OWNER_EVIDENCE_SHA256`, or explicit CLI arguments). The index and each evidence document bind accepted owner decisions to exact subject hashes and revisions. This is a pinned transport for already published owner evidence, not a replacement approval authority. A path, URL, hash, revision, or `accepted` value inside the release manifest cannot self-authenticate.

Adapter execution is skipped unless a reviewed Linux bubblewrap runtime can isolate the Python runtime, use separate network and PID namespaces, drop capabilities, and pass synthetic filesystem/socket/child-process canaries. Canary failure diagnostics include a bounded, path-redacted summary of the synthetic subprocess result; package/fixture contents and raw owner-adapter stderr are not published. Each adapter, explicitly declared dependency, runtime schema, field inventory, and fixture is read into bounded immutable bytes once and checked against its pinned SHA-256. Admission to the verified-byte cache enforces the same aggregate ceiling used for execution snapshots: at most 512 unique paths and 128 MiB retained, with each read capped by the remaining byte capacity. Repeated references to one path reuse the same bytes only when the pinned hash agrees. Schema, inventory, and fixture validation parse those same verified bytes, and the same bytes are copied into sealed in-memory files for execution. Bubblewrap places adapter/schemas/inventory/fixtures in a fresh read-only `/release` tree and declared dependencies in a separate read-only `/acv1-dependencies` tree. A trusted `-I -B -S` bootstrap adds only that sealed dependency tree to `sys.path` and executes the sealed adapter bytes; host package paths, the current directory, site packages, and undeclared package files are not import roots. Mutable package paths are never mounted or reopened for execution. The runner bounds input/output and timeout and kills the process group on timeout or output overflow. A platform without the sealed-snapshot runtime or enforceable sandbox fails closed with an execution prerequisite; the macOS `sandbox-exec` command is not treated as a supported security boundary. `--offline` alone is not an isolation guarantee. This verifier makes no network/provider calls itself. An offline fixture pass proves only owner fixture conformance; producer/consumer runtime integration, server authorization, ledger behavior, live access, and global acceptance remain separate.
